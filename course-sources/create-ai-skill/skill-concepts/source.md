# Skill Concepts

Understand what an AI skill is and why reusable instructions save time.

## Learning Cards

### Card 1: What is an AI skill?

An AI skill is a reusable set of instructions for doing a specific task well. It helps AI repeat a workflow consistently instead of being re-explained each time.

**Key idea:** A skill is a reusable instruction set for a repeated task.

### Card 2: How is a skill different from a prompt?

A prompt is usually a one-time instruction. A skill is packaged guidance that can be reused whenever the same type of task appears.

**Key idea:** Prompts are one-off — skills are reusable.

### Card 3: What should my first skill do?

Your first skill should solve one repeated task, such as rewriting emails, summarizing calls, creating reports, or formatting notes. Keep it specific and easy to test.

**Key idea:** One repeated task, specific and testable.

### Card 4: What goes inside a useful skill?

A useful skill includes purpose, steps, style preferences, output format, examples, and limits. These details help the AI produce consistent results.

**Key idea:** Purpose + steps + format + examples = useful skill.

### Card 5: Why do skills improve consistency?

Skills reduce the need to remember every instruction each time. They give the AI a stable way to approach the same task repeatedly.

**Key idea:** Skills create reliable, repeatable AI behavior.

### Card 6: What is the easiest skill template?

Use a simple structure: purpose, when to use it, steps to follow, output format, examples, and what to avoid. That is enough for many beginner skills.

**Key idea:** Purpose, steps, format, examples, limits — that is your template.
