# Agent Workflows

See how agents plan, act, check results, and improve through feedback.

## Learning Cards

### 1. What is an agent workflow?

An agent workflow is the path from request to result. It includes the trigger, input, steps, tools, checks, approvals, and final output.

**Takeaway:** A workflow shows how the agent gets work done.

### 2. What is a trigger?

A trigger is what starts the agent. It could be a button click, new email, uploaded file, form submission, schedule, or manual request.

**Takeaway:** The trigger starts the agent workflow.

### 3. How does an agent plan?

Planning means the agent breaks the goal into smaller steps. Simple agents may follow fixed steps, while more advanced agents may choose steps based on the situation.

**Takeaway:** Planning turns a goal into steps.

### 4. How does an agent act?

The agent acts by using tools or producing outputs. It might search, read, draft, summarize, compare, classify, or create a next-step recommendation.

**Takeaway:** Actions are the workflow steps in motion.

### 5. Why should an agent check its work?

Checking helps catch missing information, weak evidence, wrong format, or risky actions. A good workflow includes at least one review step before the final result.

**Takeaway:** Checking turns output into trustworthy work.

### 6. What is a retry?

A retry happens when the agent notices a problem and tries again. For example, if search results are weak, it can search with better keywords.

**Takeaway:** Retries help agents recover from weak results.

### 7. What is human-in-the-loop?

Human-in-the-loop means a person reviews or approves important steps. This is especially useful before sending messages, changing data, or making decisions.

**Takeaway:** Human review keeps important steps controlled.

### 8. How do you improve a workflow?

Watch where the agent fails, then adjust the inputs, instructions, tools, examples, or approval steps. Agent design improves through testing.

**Takeaway:** Better workflows come from testing and revision.
