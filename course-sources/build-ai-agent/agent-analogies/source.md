# Analogies & Myths

Clear up common misunderstandings about what AI agents can and cannot do.

## Learning Cards

### Card 1: How is an agent like an assistant?

An agent can take a goal and work through steps instead of only answering one question. It still needs supervision, especially at first. It is like a new assistant who can work quickly but needs a clear brief and review.

**Key idea:** Capable but supervised — especially at the start.

### Card 2: Why should my agent start with one task?

A narrow task is easier to test and improve. Broad agents are harder to control because success is unclear. It is like teaching someone one recipe before asking them to run the whole restaurant.

**Key idea:** One task first — then expand.

### Card 3: What are tools in an agent?

Tools give the agent specific abilities it would not have from language alone. They turn advice into action. It is like giving a worker a phone, calendar, calculator, and filing cabinet.

**Key idea:** Tools are what give agents real-world reach.

### Card 4: Is an agent always autonomous?

No, many useful agents are partially supervised. For beginners, the safest agents suggest actions and wait for human approval.

**Key idea:** Supervised agents are safer and still very useful.

### Card 5: Does a smarter model guarantee a better agent?

No, the model is only one part. Good instructions, useful tools, testing, and safety boundaries often matter just as much.

**Key idea:** Instructions and tools matter as much as the model.
