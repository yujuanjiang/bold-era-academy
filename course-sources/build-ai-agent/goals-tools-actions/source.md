# Goals, Tools, and Actions

Learn the core building blocks every useful AI agent needs.

## Learning Cards

### 1. What is an agent goal?

The goal tells the agent what outcome to work toward. A strong goal is specific, useful, and easy to check when the work is finished.

**Takeaway:** A good goal is specific and checkable.

### 2. What are agent instructions?

Instructions tell the agent how to behave. They can define the role, steps, tone, limits, output format, and when the agent should ask for help.

**Takeaway:** Instructions turn a goal into behavior.

### 3. What are tools?

Tools let an agent do things beyond writing text. A tool might search the web, read a file, update a spreadsheet, send an email, or call an app.

**Takeaway:** Tools give agents real abilities.

### 4. What are actions?

Actions are the things an agent does with tools or outputs. Drafting a reply, creating a task, searching a source, and updating a record are all actions.

**Takeaway:** Actions are how agents move work forward.

### 5. Why do agents need inputs?

Inputs give the agent the information it needs to start. Inputs can be a message, file, form, customer request, meeting note, or database record.

**Takeaway:** Better inputs make better agent work possible.

### 6. What is an output format?

The output format tells the agent how to present the result. It might be a list, table, email draft, JSON object, checklist, or short summary.

**Takeaway:** Output format makes results easier to use.

### 7. Why define limits?

Limits tell the agent what not to do. For example, do not send emails, do not invent facts, do not use private data, or ask before changing records.

**Takeaway:** Limits keep agent behavior safer.

### 8. What makes a tool safe to use?

A safer tool has clear permissions, visible results, and a way for humans to approve important changes. Tools that change money, accounts, or private data need extra care.

**Takeaway:** Powerful tools need careful permissions.
