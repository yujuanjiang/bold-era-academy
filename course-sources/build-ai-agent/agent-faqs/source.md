## Learning Cards

### Card 1: Can I build an agent without coding?

Yes, many platforms offer no-code or low-code agent builders. You still need to define the goal, instructions, inputs, outputs, and review steps clearly.

**Key idea:** No code needed — but clear instructions are essential.

### Card 2: What should my first agent do?

Choose a low-risk task with a clear result, like turning meeting notes into action items. Avoid tasks involving private data, money movement, or legal decisions first.

**Key idea:** Start low-risk with a clear, reviewable output.

### Card 3: How do I know if my agent works?

Test it with a few realistic examples and compare results to what you expected. Look for accuracy, completeness, tone, and whether it follows instructions.

**Key idea:** Test with real examples — not just ideal ones.

### Card 4: Should my first agent act automatically?

For beginners, keep a human approval step before the agent sends, deletes, buys, or changes anything important. Automation should grow after trust is earned.

**Key idea:** Earn trust before removing human review.

### Card 5: What instructions should I give an agent?

Tell it its role, goal, audience, limits, output format, and when to ask for help. Clear boundaries make agent behavior more predictable.

**Key idea:** Define role, goal, limits, and format upfront.
