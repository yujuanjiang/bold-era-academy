# Agent Concepts

Learn what an AI agent is, what it needs, and how it differs from a chatbot.

## Learning Cards

### Card 1: What makes an AI agent different?

An AI agent can follow a goal, use tools, and take steps toward an outcome. A normal chatbot mostly responds to one message at a time.

**Key idea:** Agents pursue goals — chatbots respond to messages.

### Card 2: What are the basic parts of an agent?

A simple agent needs a goal, instructions, a model, tools, and a way to return results. More advanced agents may also use memory and safety checks.

**Key idea:** Goal + instructions + model + tools = agent.

### Card 3: What is an agent goal?

An agent goal tells the agent what outcome to work toward. A good goal is specific enough to guide action and simple enough to evaluate.

**Key idea:** Specific goals produce predictable agents.

### Card 4: Why do agents need tools?

Tools let an agent do things beyond writing text, such as searching, reading files, calling apps, or calculating. Without tools, the agent mainly generates responses.

**Key idea:** Tools turn responses into actions.

### Card 5: What is the simplest useful agent?

A simple useful agent handles one clear task, such as summarizing notes, drafting replies, or organizing research. Starting narrow makes it easier to trust and improve.

**Key idea:** Narrow agents are easier to trust and improve.

### Card 6: What should I test before trusting an agent?

Test normal cases, messy cases, and cases where it should refuse or ask for help. Good agents handle limits as well as successes.

**Key idea:** Test the edges, not just the easy cases.
