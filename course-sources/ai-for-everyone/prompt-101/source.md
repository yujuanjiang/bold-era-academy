# Prompt 101

Learn how to ask AI for clearer, safer, and more useful answers.

## Learning Cards

### Card 1: What is prompt engineering?

Prompt engineering means designing and improving the instructions you give an AI model so it better understands your goal and produces the kind of answer you want.

**Key idea:** Better prompts guide AI toward better answers.

### Card 2: What counts as a prompt?

A prompt is the input you give AI. It can be a simple question, a direct command, a set of steps, an example, a code snippet, or background information.

**Key idea:** A prompt is any input that guides the AI response.

### Card 3: Why does context matter?

Context helps AI understand the situation, audience, purpose, and constraints. Without context, the model has to guess what matters.

**Key idea:** Context reduces guesswork.

### Card 4: How do examples improve prompts?

Examples show the AI the pattern you want. One example can guide style, and several examples can teach format, tone, level of detail, or structure.

**Key idea:** Examples show what good output looks like.

### Card 5: What is zero-shot prompting?

Zero-shot prompting means asking directly without giving examples. It works well for simple tasks like summarizing, translating, listing ideas, or answering clear questions.

**Key idea:** Zero-shot means direct instruction, no examples.

### Card 6: What is few-shot prompting?

Few-shot prompting means giving a few input-output examples before the real request. This helps AI copy the pattern and produce a more predictable response.

**Key idea:** Few-shot prompting teaches by example.

### Card 7: How do you make a prompt specific?

Use action verbs, define the output format, name the audience, include important background, and break complex work into smaller steps.

**Key idea:** Specific prompts give AI a clearer target.

### Card 8: Why should you iterate?

Prompting is a cycle. Read the result, notice what is missing or unclear, then revise your prompt with more context, examples, limits, or format instructions.

**Key idea:** Prompting improves through feedback and revision.
